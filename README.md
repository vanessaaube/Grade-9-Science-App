# Element Quest — Grade 9 Science Quiz

A polished, mobile-friendly quiz covering the first 30 elements of the periodic table. It is built with plain HTML, CSS, and JavaScript, so it can be hosted on any basic static website service.

## Run it

1. Keep `index.html`, `styles.css`, and `app.js` together in the same folder.
2. Double-click `index.html` to open it locally, or upload all three files to a static host.
3. No build step, package manager, account, or server is required.

## Hosting options

Upload the folder contents to any static host, including GitHub Pages, Netlify, Cloudflare Pages, an ordinary web server, or a school learning platform that accepts website files. The home page must remain named `index.html`.

## Included features

- 10 questions per round, with a fresh randomized selection each time
- 150 base question prompts (30 elements × 5 question types), with additional variation in choices and incorrect-pair combinations
- Two questions from each category in every round:
  - element name → symbol
  - symbol → element name
  - similar-symbol traps
  - identify the incorrect pairing
  - mystery-element clues
- Immediate answer feedback and explanations
- Running score and progress indicator
- Final score screen and Play Again button
- Quick-reference grid for all 30 elements
- Responsive layout, iPhone safe-area support, touch-friendly controls, keyboard support, reduced-motion support, and no external dependencies

## Files

- `index.html` — app structure and screen content
- `styles.css` — responsive visual design
- `app.js` — element data, question generation, scoring, and interactions
- `README.md` — setup and hosting instructions

## Browser support

Designed for current Safari on iPhone, plus current Chrome, Edge, and Firefox. The app works offline after the files have been downloaded because it does not load external fonts, images, libraries, or services.
